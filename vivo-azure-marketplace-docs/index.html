✨ Key Features

👤 Linked Data Researcher Profiles

Structured RDF/OWL profiles, linked to external entities (ORCID, grants, publications).

🔍 Integrated Solr Search

Full-text and faceted search via Apache Solr — metadata and content indexing.

🔒 Automatic HTTPS

Let's Encrypt configured automatically as soon as a domain name is resolved.

🌐 Internationalization (i18n)

Multilingual support — interface available in French and English.

📊 Co-author Network

Configurable VCard co-author graph, VCard indexer, configurable network limit (VIVO 1.16.0).

🔗 SPARQL Endpoint

SPARQL endpoint exposed for querying RDF data — supports POST for large queries.

✏️ TinyMCE Editor

Rich editor for profiles and content pages, integrated in VIVO 1.16.0.

🏛 Supported by LYRASIS

Open source project maintained by the DuraSpace/LYRASIS community — deployed in 25+ countries.

🆕 What's New in VIVO 1.16.0

  • External VCard contributors for co-authors
  • VCard co-author graph with extended support
  • VCard indexer integrated with Solr
  • Organization editors (org editors)
  • TinyMCE integration for rich content editing
  • Configurable limit for co-author network
  • POST support for large SPARQL queries
  • Decoupled CI/CD: installation and deployment separated
