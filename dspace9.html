DSpace 9 — Dépôt institutionnel

Ubuntu 22.04 LTS · REST API · Angular · HTTPS / Let's Encrypt

Dépôt institutionnel open source de référence — déployez DSpace 9 en un clic sur Azure. Stack complète préconfigurée : Tomcat (REST API), Angular (frontend), Nginx, PostgreSQL, Solr et certificat HTTPS automatique.

✨ Fonctionnalités clés

📦 REST API moderne

API REST complète HAL+JSON pour l'intégration avec des systèmes tiers et des clients Angular.

🖥 Interface Angular

Frontend Angular entièrement responsive — navigation, dépôt et consultation de collections.

🔍 Recherche Solr

Recherche full-text et par facettes — indexation des métadonnées et du contenu des objets numériques.

🔒 HTTPS automatique

Certificate Let's Encrypt provisionné automatiquement — surveillance DNS par dspace-dns-watch.timer.

🗄 PostgreSQL intégré

Base de données relationnelle préconfigurée pour DSpace — schéma, utilisateurs et droits initialisés.

☁️ Prêt pour Azure

Déploiement via cloud-init — VM opérationnelle en quelques minutes depuis Azure Marketplace.

🚀 Mise en route

1

Connexion SSH à la VM

Après déploiement depuis le Marketplace, connectez-vous en SSH avec le nom d'utilisateur choisi.

ssh <admin-username>@<your-vm-ip>
2

Créer le compte administrateur DSpace

Créez le premier compte administrateur via la ligne de commande DSpace.

sudo /opt/dspace/bin/dspace create-administrator
3

Vérifier les services

Confirmez que tous les services sont bien démarrés.

sudo systemctl status tomcat sudo systemctl status dspace-frontend sudo systemctl status nginx sudo systemctl status postgresql sudo systemctl status solr
4

Accéder aux interfaces

DSpace expose plusieurs points d'accès sur votre VM :

InterfaceURL
Frontend Angularhttps://<ip>/
Connexion adminhttps://<ip>/login
REST APIhttps://<ip>/server
Solr (local uniquement)http://localhost:8983/solr
5

Certificat SSL / Let's Encrypt

Un certificat auto-signé est actif par défaut. Dès qu'un nom de domaine (FQDN) résout vers votre IP, dspace-dns-watch.timer détecte la résolution et provisionne automatiquement un certificat Let's Encrypt.

sudo cat /root/.dspace-credentials
