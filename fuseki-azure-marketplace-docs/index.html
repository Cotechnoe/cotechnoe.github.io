🚀 Démarrage rapide

Après déploiement depuis Azure Marketplace, Fuseki est immédiatement accessible.

1. Accéder à l'interface Web

http://<votre-ip-vm>:3030

2. Déployer le service systemd via Makefile

# Déployer le service sur la VM distante
make service-deploy HOST=<ip-vm> SERVICE_FILE=fuseki-d2s-v3.service

# Activer et démarrer le service
make service-enable HOST=<ip-vm>
make service-start  HOST=<ip-vm>

3. Sécuriser avec Shiro

# Générer les credentials Shiro hashés
make shiro-generate

# Déployer la configuration Shiro sur la VM
make shiro-deploy-hashed HOST=<ip-vm>
